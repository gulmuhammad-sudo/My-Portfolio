## 🚀 About

Welcome to my **Cybersecurity Portfolio**.

This website is designed to showcase my journey and work in **Cybersecurity, Security Operations, Governance Risk & Compliance (GRC), Network Security, and Security Monitoring**.

The portfolio uses a **dark cyber-themed interface** with interactive elements, terminal-inspired visuals, responsive layouts, and modern UI components.

> 🔐 **Mission:** Build practical cybersecurity solutions, continuously improve security skills, and turn real-world security challenges into meaningful projects.
