## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎨 **Dark Cyber Theme** | Immersive dark design with neon green accents (🔰 `#0afb60`) |
| 📱 **Fully Responsive** | Optimized for mobile, tablet, and desktop screens |
| 🖥️ **Interactive Terminal** | Hero section with a live terminal-style display |
| 🧭 **Smooth Navigation** | Sticky header with smooth scrolling and active section highlighting |
| 📱 **Mobile Hamburger Menu** | Clean mobile navigation with animated toggle |
| 🛡️ **Project Showcase** | Display security projects with tags and descriptions |
| 🔬 **Security Labs Section** | Highlight practical cybersecurity lab work |
| 📬 **Contact Form** | Functional contact form with FormSubmit integration |

## 🎯 Purpose

This portfolio serves as a professional showcase for **Gul Muhammad** — a Cybersecurity professional specializing in:

- 🔐 **GRC & ISMS** — Governance, Risk & Compliance, ISO 27001
- 🛡️ **SOC Operations** — Security monitoring, incident response
- 🖥️ **SIEM & Endpoint Security** — Wazuh, Sysmon, Windows security
